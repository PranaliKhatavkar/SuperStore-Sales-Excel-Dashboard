# SuperStore-Sales-Excel-Dashboard
## Project Overview
This project is an interactive Excel dashboard created using the SuperStore sales dataset.
The dashboard analyzes sales performance, profitability, customers, products, regions, segments, payment modes and shipping methods.

## Objective
The main objective of this project is to analyze SuperStore sales data and create an interactive dashboard that helps identify:

* Sales performance
* Profitability
* Top-performing categories and products
* Regional performance
* Customer segment performance
* Payment preferences
* Shipping performance
* Monthly sales trends

## Tools Used
* Microsoft Excel
* Excel Tables
* PivotTables
* PivotCharts
* Slicers
* Timeline
* Excel formulas

## Key KPIs
* Total Sales
* Total Profit
* Profit Margin
* Total Orders
* Total Customers
* Total Quantity

## Dashboard Analysis
The dashboard provides analysis of:
1. Monthly Sales Trend
2. Sales by Category
3. Sales & Profit by Region
4. Sales & Profit by Segment
5. Top 10 Products by Sales
6. Sales by Payment Mode

## Interactive Features
The dashboard includes slicers for:
* Region
* Category
* Segment
* Ship Mode
* Payment Mode
A date timeline is also included to analyze performance over different time periods.

## Key Insights
The dashboard can be used to identify:
* Highest-performing sales categories
* Most profitable regions
* High-performing customer segments
* Top-selling products
* Low-profit or loss-making sub-categories
* Monthly sales trends
* Shipping and payment patterns

## Dataset
The project uses the SuperStore sales dataset containing information about orders, customers, products, sales, quantity, profit, shipping and payment methods.

## Conclusion

This project demonstrates how Excel can be used for data cleaning, analysis, visualization and interactive dashboard development. It provides a consolidated view of business performance and supports data-driven analysis of sales and profitability.
